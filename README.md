
# UPI Transaction Analytics & Performance Insights

## 📊 Project Overview

This project analyzes **250,000 UPI transactions** from 2024 to understand transaction trends, payment behavior, operational performance, and potential fraud indicators.

An interactive **Microsoft Excel dashboard** was developed using PivotTables, PivotCharts, KPIs, and Slicers to convert raw transaction data into meaningful business insights.

## 🎯 Objectives

- Analyze UPI transaction trends and patterns.
- Monitor overall transaction performance.
- Identify peak transaction hours.
- Compare transaction values across merchant categories.
- Analyze transaction types and payment behavior.
- Identify banks and states with higher transaction activity.
- Monitor successful and failed transactions.
- Analyze potential fraud indicators.

## 📈 Dashboard Charts

### 1. Monthly Transaction Value Trend
**Chart Type:** Line Chart

Shows the month-wise movement of transaction value and helps identify periods with relatively high or low transaction activity.

### 2. Transaction Value by Merchant Category
**Chart Type:** Horizontal Bar Chart

Compares transaction values across different merchant categories and identifies categories with higher transaction value.

### 3. Top Sender Banks by Transaction Count
**Chart Type:** Horizontal Bar Chart

Compares transaction counts across sender banks and identifies banks with higher transaction activity.

### 4. Transactions by Hour of Day
**Chart Type:** Line Chart

Shows how transaction activity changes throughout the day and helps identify peak transaction periods.

### 5. Transaction by Type
**Chart Type:** Donut Chart

Shows the distribution of different transaction types.

- P2P: 45%
- P2M: 35%
- Bill Payment: 15%
- Recharge: 5%

### 6. Top States by Transaction Value
**Chart Type:** Horizontal Bar Chart

Compares transaction values across different states and highlights regions with higher transaction activity.

## 🎛️ Interactive Slicers

The dashboard provides interactive filters for:

- Transaction Status
- Merchant Category
- Sender State
- Device Type
- Is Weekend

These slicers allow users to explore specific segments of the transaction data.

## 🔍 Key Findings

- 250,000 UPI transactions were analyzed.
- Total transaction value is approximately ₹327.94 million.
- The overall success rate is 95%.
- Shopping has the highest transaction value among the displayed merchant categories.
- P2P is the most common transaction type.
- Transaction activity is highest during the evening hours.
- SBI has the highest transaction count among the displayed sender banks.
- Maharashtra has the highest transaction value among the displayed states.

## 💡 Recommendations

- Monitor failed transactions to improve the overall success rate.
- Monitor peak transaction hours to maintain reliable transaction performance.
